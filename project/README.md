# مشروع تأمين الـ REST API (المهمة الثالثة)

مشروع متجر إلكتروني مبني باستخدام Node.js و Express ومربوط بقاعدة بيانات PostgreSQL مع تطبيق كافة معايير الأمان وتأمين المسارات.

---

## كيفية تشغيل المشروع

1. تثبيت المكتبات:
```bash
npm install
```

2. إعداد ملف البيئة:
قم بنسخ ملف `.env.example` إلى ملف `.env`:
```bash
cp .env.example .env
```

3. تشغيل السيرفر:
```bash
node src/server.js
```
سيعمل السيرفر على الرابط: `http://localhost:3000`

---

## كيفية الفحص بـ Postman

1. افتح برنامج Postman.
2. اضغط Import واختر ملف `postman_collection.json` المرفق.
3. شغل الاختبارات الـ 15 للتأكد من نتائج الحماية وإرجاع رموز الحالة المناسبة (201, 409, 200, 401, 403, 400, 429, 404).
